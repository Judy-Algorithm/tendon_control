# 原生肌腱工作台 V2：交付范围

## 三项验收分开看

| 项目 | 结论 | 实际能力 |
|---|---|---|
| 教学演示 | 主要交互完成，模型范围有限 | 四个独立入口、四步 MyoHand 引导、紧凑标题、原生路径、全通道图、参数比较与导出；MANO 为独立原理示意 |
| 原生求解复现 | 部分完成 | 本地实际执行全43肌肉 OpenSim SO、全39肌肉 MyoHand 前向/自定义控制；原48动作逐一登记，未支持或失败项不替换 |
| 线上可重新求解 | 尚未接通 | Vercel 提供真实原生结果回放、已有参数比较和导出；任意新参数重算需要本地原生服务 |

公开任意求解还需要一个可长期运行 OpenSim/MyoSuite Python 的后端及其授权部署、认证和任务队列。没有开放用户电脑、建立公网隧道或新付费服务。前端不会将滑块插值当成原生计算。

## 这轮加入了什么

1. 原生 OpenSim 与 MyoHand 分别读取各自骨骼、通道、肌腱路径和关节状态。43 与39是肌肉激活通道数；MyoHand 的44条 tendon 中另有5条非驱动视觉通路。
2. 保存命名基线 → 改全局/单肌肉参数 → 原生重算或读取完全匹配的记录 → 同步并排/叠加 → 导出。未计算参数不会改写旧结果。
3. 激活热图、全部肌肉的带符号关节力矩图、角度/肌力/激活曲线、力矩分项图、真实采样点参数响应图。支持 PNG、SVG、CSV、JSON 和带模型哈希/单位的参数预设。
4. MyoHand 依次解释“发指令、肌肉响应、拉动关节、手动起来”，同时保留控制与实际激活的差别。目标跟踪由新增控制器完成，不称为 MyoHand 自动提供 SO。
5. MANO 单独解释形状、姿态、表面变形、关键点。不借用其他模型肌腱，不输出肌肉激活；未重新分发受限 MANO 权重或真实网格。
6. 左手源模型镜像与异侧手动作轴向经过单独修复/审核；旧模型、错误映射记录与失败证据保留，不在显示层偷偷修饰。

## 参数到底能改多少

- OpenSim：每条肌肉3个长度/力量字段，共129个单肌肉编辑位置，另有3个全局倍率。外载荷幅值、未冻结示例的动作时长/角度另列。包绕、关节拓扑、惯性、肌肉类等保持只读。
- MyoHand：每条肌肉2个力/响应时间倍率，共78个单肌肉编辑位置，另有2个全局倍率；短指令、初始化和已接入控制器设置另列。
- OpenSim检查器枚举18项模型属性、234项坐标属性、1,032项肌肉属性、210项骨体属性、170项关节属性、18项约束属性与10项SO默认设置。
- MyoHand检查器枚举480个编译模型字段和29个编译选项字段。大数组按形状、类型、哈希摘要展示。

这些是字段/所属对象的条目数，不是独立可辨识的人体参数数目。界面可调范围是本次工程操作范围，不声称是个人生理范围。激活时间常数在当前SO中不作为可调实验。

## 独立检查与真实重算

- OpenSim基线及Fmax×1.10：独立原生SO复算，激活差≤3.31×10⁻¹⁰、reserve差≤2.12×10⁻¹⁴ N·m；另有模型镜像、骨网格、角度映射和力矩传递检查。
- MyoHand：5组记录共265帧独立重放相同控制，q/qvel/激活/肌力/广义驱动力差≤5×10⁻¹¹；这不是目标跟踪成功的替代检查。
- Scale→IK示例实际使用90个合成体附着标记、31帧及1.05倍缩放；标记RMS0.527μm，最大2.704μm。它是合成自检，不是个人21点重建证据。
- 实际浏览器提交未收录的OpenSim Fmax×1.07设置，耗时约11.27秒（包含网页轮询；原生计算约10.36秒）；51帧通过声明检查，最大激活变化0.0315，姿态和载荷保持不变。
- 实际浏览器还完成MyoHand力尺度×1.13、时间尺度×1.3的新求解，以及原生控制重放独立检查。
- 本地API实测错误模型、未知字段、跨来源和超大请求拒绝；实际取消运行不返回结果；越界参数保留为失败。
- 独立审查见 `RELEASE_REVIEW_v002.md`、`QA_UI_FINAL_G.md` 及相应逐项JSON。原ROM、手机、200%文本布局、无WebGL、断网/空结果、失败帧和图表导出均有专项检查。审查者模拟新手流程，不声称做过真人用户研究。

## 保留的限制

1. 原48动作并未全部复现，不能把另设的小幅原生动作计入原动作成功率。
2. OpenSim本次“通过”是所声明的原生输出/界限/力与约化力矩对账；没有把5% reserve作为引擎默认规则。小惯性会放大加速度约束残差，低Nm残差不保证完整前向重放成功。
3. FDPI在屈曲位仍有与反射右手不完全一致的原生包绕行为；保留当前选定模型实际路径，未美化成对称手。
4. 通常直接给关节角的记录跳过Scale/IK；专门的合成Scale/IK示例分开标记。未接入真实个人数据重建、任意包绕编辑、多肌肉类切换或Moco求解。
5. 前向MyoHand与逆向SO回答不同问题，43/39通道不做虚假的一对一比较。各参数固定于整段轨迹，无逐帧调参以制造成功。
6. 新运行保留于本地服务和当前网页会话，刷新前应导出JSON。已交付原生记录及其哈希、参数、单位随仓库和下载保存。
