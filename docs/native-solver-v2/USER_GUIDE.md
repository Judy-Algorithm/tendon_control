# 原生肌腱工作台

## 先玩一次

1. 进入 MyoHand，播放默认短指令；沿上方四步看控制、激活、拉力、力矩与运动的区别。
2. 选择任意肌肉和关节。3D 高亮对应原生通道，下方可查看所有 39 个通道，绝非只求选中的一条肌肉。
3. 点击「保存基线」，再选择同动作的已有调参记录；连接本地服务后也可直接修改参数并点击「重新求解」。
4. 查看同步 3D 与响应曲线，导出 PNG/SVG 图片、CSV 数值或带参数和检查信息的 JSON。

OpenSim 同样支持全部 43 通道。它先从规定运动计算所需关节力矩，再通过静态优化分配肌肉力与辅助力矩；这不是 MyoHand 的前向控制过程。

## 线上没有假求解

生产网站由 Vercel 托管静态前端与真实原生结果。没有连接计算服务时，按钮明确显示不能重算；改变滑块不会伪造一条新曲线。已有参数实验可以正常对比和导出。

本地计算服务同时提供同一网页，且只绑定 `127.0.0.1`。配置现有环境后启动：

```sh
OPENSIM_PYTHON=/absolute/path/to/opensim/python \
OPENSIM_MODEL=/absolute/path/to/verified/model.osim \
MYOHAND_PYTHON=/absolute/path/to/myosuite/python \
PORT=4181 node scripts/native-v2/server.mjs
```

打开 `http://127.0.0.1:4181`。OpenSim 模型哈希必须与选中记录一致；缩放模型和基准模型不可静默混用。一个引擎未配置不影响另一个引擎。请求串行、可取消，每次最多计算 900 秒；超时和失败保留日志，不将未完成轨迹显示为完整结果。服务不接收用户任意文件路径或命令，不开放公网。

## 哪些可以改

| 引擎 | 已接入重算的参数 | 当前只读 / 不代表可任意拟合 |
|---|---|---|
| OpenSim | 全局及单肌肉最大等长力、最优纤维长度、肌腱松弛长度；非冻结动作的目标角、时长；声明位置和方向的外载荷 | 完整模型参数快照中的质量惯量、几何通路、包绕、耦合约束和未接入的原生属性 |
| MyoHand | 全局及单肌肉肌力/激活时间倍率；短指令幅度和时段；可用动作时长；自定义跟踪器增益 | 完整编译模型快照中的几何、关节、惯性和其他未接入属性 |

上下限是本工作台的经检查操作范围，不是个体生理范围。每个引擎保留自身参数语义，不能将 MyoHand 的力尺度直接当成 OpenSim 的最大等长力。几何、载荷或时序改变后不能称作纯肌肉参数对照。

## 图怎么看

- 激活图：纵轴为全部肌肉通道，横轴为时间，色标固定 0–1。
- 肌肉力矩图：纵轴为全部肌肉通道，横轴为当前关节上的带符号力矩（N·m），不是“关节力矩的激活”。
- 关节力矩图：纵轴为关节，横轴为时间；显示肌肉贡献，不等于完整所需力矩。
- 响应曲线：控制/激活、肌力、角度分别绘制，不混用单位；目标与实际角度区分。
- 分项曲线：OpenSim 对比所需、肌肉、辅助力矩及剩余误差；MyoHand 分别显示执行器、约束、被动力和动力学偏置项，不把部分分项误称为完整平衡。
- 参数响应图：同一输入只改一个全局肌肉参数时，显示两次真实计算的点，不插值冒充额外实验。OpenSim 角度是规定输入，MyoHand 角度是运动响应。
- 基线可命名、与当前结果并排或叠加；「读取对应记录」只接受完全匹配的已计算设置。本会话新计算可重新选择，刷新前请导出 JSON 保存。
- 灰色失败帧不是零激活。CSV 保留原始值及有效标记，JSON 保留全部检查、模型标识和请求。

## 源模型与范围

OpenSim 左手源文件存在不完整镜像；工作台使用单独版本化、经原生引擎重算的修复模型，原始文件与原始记录保留。修复范围和独立检查见 `OPENSIM_CANONICAL_REPAIR.json` 与 `QA_CANONICAL_MIRROR.md`，不是在显示端拉伸骨骼掩盖错误。

原 ROM 页与原生模型的坐标、关节限位、通路命名并非一一对应。查看「动作覆盖与失败记录」可逐项确认原 48 动作，另列的新原生坐标动作不冒充原动作。数值成功、动作跟踪成功、低辅助力矩是不同检查。

Scale/IK 演示使用合成标记点与已知缩放，不代表真实个人重建。Moco 尚未接入本工作台。MANO 页只有原理示意，不生成生理激活。
