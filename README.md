# 肌腱控制

## 原生求解工作台（V2）

顶部四个入口：**肌腱控制 → OpenSim → MyoHand → MANO**。原 ROM 教学页保留；两个原生页分别读取自己的模型、路径与计算结果，不共用一套示意肌腱。

- **OpenSim**：43 肌肉、23 独立坐标；查看实际 ID/SO 记录，以及单独的合成 Scale/IK 演示。参数包括全局和单肌肉最大等长力、最优纤维长度、肌腱松弛长度。每条记录列出实际执行的步骤与失败帧。
- **MyoHand**：39 个原生肌肉执行器。四步依次是「发指令 → 肌肉响应 → 拉动关节 → 手动起来」。短指令是原生前向仿真；跟踪目标另用明确标注的自定义控制器，并报告跟踪误差。
- **MANO**：独立解释形状、姿态、网格和关键点；原理示意不假装具有肌肉、肌腱或动力学，不分发受限模型权重。
- **比较与导出**：保存基线后比较原参数/新参数的同步 3D、全通道激活、逐肌肉带符号力矩及响应曲线；导出 PNG、SVG、CSV、JSON 和参数快照。未求解的参数不会修改已有结果。

**线上与本地的区别**：Vercel 版本可交互回放已计算的原生记录、切换已有参数实验并生成图表。任意新参数的原生计算需要本地 Python 引擎；浏览器本身不运行 OpenSim。连接方式、源模型修复与动作覆盖见 [工作台使用说明](docs/native-solver-v2/USER_GUIDE.md)。原始 ROM 中的 48 个方向不都存在于两个原生模型中，不支持项和失败记录不会隐藏或静默缩小角度。

以下为保留的原 ROM 教学页说明，不代表新增原生求解页的数据和能力。

ROM 动作与肌腱通路控制面板：原 16 个关节、23 个自由度、46 个方向按钮，另加第4、5掌骨 CMC 联动示意（1 个控制组、2 个方向按钮）。展开关节并点击动作，同时显示关联肌腱、转动对应骨骼及下游指骨。用 Display / Hide 控制路径和箭头；支持暂停、重播、回中立位、角度拖动和斜视／掌侧／侧面观察。鼠标拖动旋转，滚轮缩放。

鼠标悬停在骨头上时，只在鼠标旁显示该骨头的完整中文名称；移开、拖动或按 Esc 时隐藏。不再按展开关节常驻显示多条骨名和引线。识别覆盖全部 29 个骨骼网格，不受当前关节限制，并随旋转、缩放及 ROM 动作重新判断；被前景骨头或肌腱遮挡的骨头不显示名称。原肌腱标注与桡侧／尺侧方位提示保留。

画面在手腕附近用小字和细箭头标出桡侧（拇指侧）、尺侧（小指侧）。方位锚点位于桡骨、尺骨远端两侧，随视角变化；窄屏简写为「桡侧」「尺侧」以贴近手腕，标签避让当前骨名、肌腱名称和底部视角按钮；所有关节收起时仍可辨认手的方位。

右侧顶部支持肌肉缩写搜索：输入 FDS3 即显示单条通路，输入 FDS 显示同组通路；忽略大小写、空格、下划线和连字符，也支持全角字母数字。匹配结果显示中文名称，点击一项可单独查看。搜索会停止 ROM 并回到中立位；清除后隐藏搜索通路，展开关节则退出搜索。搜索范围为现有 37 条启用通路，未匹配时明确提示。搜索可重新显示先前手动隐藏的对应通路。

## 运行

```sh

```

打开 http://127.0.0.1:4173。纯静态网站，无构建步骤、CDN 或服务器依赖。部署 Vercel 时选择 Other，构建命令与输出目录留空。

## 数据

- 右侧 ROM 控制表和三维手部几何来自右手通用包 `General_right_native_20261116/General_right_native_REVIEW.osim`：显示 18 个关节组、24 个手/前臂功能坐标和全部 43 个 Muscle 名称；肌肉方向关联按模型默认位力臂计算，阈值为绝对值 0.01 mm。`radioulnar / forearm_rotation`、CMC4/CMC5 约束、骨骼网格和中立位肌肉通路均由该原生右手模型导出。模型状态为 `REVIEW`，没有应用受试者缩放。
- 网页显示坐标通过一个保持手性的刚体旋转对齐原视口，不做左右镜像。模型中的关节名、Coordinate 名、范围和 43 个 Muscle 原名保持不变。
- 原模型没有独立拇指 MCP 外展／内收 Coordinate，因此 ROM 面板不显示该自由度。第 4、5 掌骨 CMC 联动按模型的 `4cmc_flexion / CMC5_r1` 约束显示。
- 正负力臂转换为具体动作，而不是统一解释为屈曲／伸展。无名指、小指 MCP 侧向正向为内收；中指侧向使用桡偏／尺偏。
- 所有动作关联均为中立位结果，不代表全姿态的固定解剖功能或独立可控性。
- 通路名称下的「起止位置」仍是解剖参考文字；三维线本身使用右手模型的中立位 `GeometryPath`（含可用的包绕采样点），不把文字描述冒充精确附着坐标。

## ROM 动作示意

- 每次只演示一个选定自由度；下游骨骼随父关节作刚体转动，切换动作会重置其他关节。
- PIP／DIP 伸展从 65% 预屈曲位置回到 0°，避免从中立位开始时看不出运动。
- 肌腱线路从模型中立位路径随关节平滑变形，并保留圆形端帽。该近似不求解肌力、肌腹收缩、骨面碰撞或任意姿态下的 OpenSim 包绕；中立位肌腱关联不等于任意姿态下的驱动力关系。
- 第4、5掌骨 CMC 使用两个独立基部示意轴、一个联动滑块：第4掌骨转动滑块角度的一半，第5掌骨转动完整角度；示意上限分别为 10°、20°。掌骨携带各自整根手指，不额外弯曲 MCP/PIP/DIP。原始 SHM 表与网格保持不变；该新增项未配置驱动肌腱。参数来源和局限见 [CMC 联动说明](docs/cmc-coupling.md)。
- 页面默认显示中立位，所有关节收起，不自动播放；选择 ROM 动作后开始演示。启用系统减少动态效果时，选择动作后仍等待手动播放。

模型摘要及坐标方向约定见 `docs/data-provenance.json`。仓库不包含 EMG、录制数据、模型权重、服务器信息或认证凭据。
